Choosing clear, accessible colours for BC marine science & fisheries

pacfishpalettes helps fisheries scientists, analysts, and communicators pick consistent, publication-ready colour palettes without guessing hex codes or accidentally using colours that blur together for colourblind readers. Every species palette is inspired by real British Columbia and North Pacific marine life, while every guild, fleet, survey, and DFO branch palette is mathematically tested for colour-vision accessibility.

Using pacfishpalettes in R

Install the lightweight R package directly from GitHub (base R core with optional ggplot2, paletteer, and rphylopic support):

# Install from GitHub
remotes::install_github("pacfishpalettes/pacfishpalettes")

library(pacfishpalettes)
library(ggplot2)

# Lookup by common name, scientific name, or DFO species code
pac_pal("yelloweye_rockfish")
pac_pal("Sebastes_ruberrimus", n = 5)
pac_pal(442)  # Yelloweye Rockfish HART/DFO code

# Drop-in ggplot2 scales & gfsynopsis helpers
cols <- pac_species_colors(c("Chinook Salmon", "Sockeye Salmon", "Coho Salmon"))
surv <- pac_survey_colors()

ggplot(df, aes(year, biomass, colour = survey)) +
  geom_line(linewidth = 1) +
  scale_colour_pac_d("bc_synoptic_surveys") +
  add_pac_shape("sebastes", xmin = 2018, xmax = 2023, ymin = 80, ymax = 100)

# Audit any custom palette for colorblind safety in pure R
pac_check_cvd("bc_groundfish_guilds")
